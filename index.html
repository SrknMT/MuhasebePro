Ayarlar & Yedekleme

Firebase Bağlantısı

Verileriniz Firebase Firestore'da saklanır. Kendi Firebase projenizin config bilgilerini buraya yapıştırabilirsiniz.

Güvenlik notu: Bu dosyayı GitHub'a yüklerken Firebase config'iniz görünür olur — bu normaldir. Önemli olan Firestore kurallarınızın yalnızca size açık olmasıdır. Örnek kural: rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if request.auth != null; } } }

İşletme Ayarları (Genel)

Genel ayarlar, kilidi açık yıllar için geçerlidir (şu anki yıl: ). Geçmiş yılların rakamlarının değişmemesi için Muhasebe & Vergi sekmesinde ilgili yılı seçip "Bu Yılı Kilitle" ile dondurun; kilitli yılın sabit giderleri ve vergi dilimleri oradan yıla özel düzenlenir.
